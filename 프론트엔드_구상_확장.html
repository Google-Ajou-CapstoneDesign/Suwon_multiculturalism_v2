이번 통합에서 내린 판단

  • 임금계산기와 진정서를 끊었습니다. 계산 결과가 내비게이터의 '체불임금총액' 칸으로 자동으로 넘어가지 않습니다. 사용자가 보고 직접 적습니다. 스스로 임금을 확인하는 계산(삼쩜삼 선례)과, 다툼 있는 체불액을 확정해 서류에 넣는 행위는 법적 성격이 다르기 때문입니다
  • Fact-Mapping의 3색 태그. 자동채움(teal) / 원문그대로(blue) / 공란유지(gray)를 화면에서 눈으로 구분되게 했습니다. '위반 법조항'과 '의학적 소견'이 회색 공란으로 남아 있는 게 보이는 것 자체가 법적 방어 논리의 시각적 증거입니다
  • 내비게이터 패널은 나침반 위에서 피어오릅니다. 전체 화면을 덮지 않고, 배경을 살짝 어둡게 해서 되돌아갈 수 있다는 걸 남겨뒀습니다. 스케치대로 선택적으로 쓰는 기능이라는 성격을 유지하려는 것입니다
  • AI 응답을 4개 레이어로 색 분리. 팩트=teal / 안전고지=amber / 라우팅=blue outline / 지역기관=white. 어디까지가 사실이고 어디부터가 '판단하지 않겠다'는 선언인지 사용자가 색으로 구분할 수 있습니다

기타 설정에 넣은 것과 그 이유

  • 화면 잠금(PIN). 사업주가 폰을 보자고 하는 상황이 실제로 생깁니다. 근무기록장은 그 자체로 증거라서, 잠금이 없으면 기록하는 행위 자체가 위험해집니다
  • 근무기록 내보내기(PDF). 앱을 지우거나 폰을 바꿔도 증거가 남아야 합니다. 노무사·노동청에 그대로 낼 수 있는 형태로 뽑는 기능입니다
  • 글자 크기. 중장년 이용자 비중과 현장 조도를 고려한 접근성 항목입니다
  • 알림. 비자 만료 D-30, 급여일 미입금, 근무기록 미작성 세 가지만 둡니다. 알림이 많아지면 정작 중요한 비자 알림을 놓칩니다

수환이에게 넘길 때 확인할 점

  • 최저임금 기본값은 확인 필요. 시안에는 자리표시자로 넣어뒀으니 고용노동부 고시로 반드시 대조할 것
  • 중국어가 추가되면서 UI 문자열이 4배가 됐습니다. 지금처럼 한 파일에 두면 관리가 안 되니, 언어별 JSON 분리가 필요한 시점입니다
  • 근무기록장 시트는 화면을 다 덮지 않고 하단 내비게이션을 남깁니다(달력 아이콘을 다시 눌러 닫는 스케치 동작을 살리기 위함). RN에서는 BottomSheet 라이브러리 대신 Animated.View + translateY로 직접 구현하는 편이 이 동작에 맞습니다
  • GPS 배지는 '위치 인증 완료 / 사업장 외부 기록' 두 상태만 둡니다. 판정하지 않고 사실만 기록한다는 원칙과 맞물리는 부분이라 문구를 임의로 바꾸지 말 것
