임금계산기 · 최종확정명세 반영 내역

  • 최저임금을 연도별 테이블로 뺐습니다. MINWAGE_TABLE에 2025년 10,030원과 2026년 10,320원(월 환산 2,156,880원 · 209시간)을 넣었습니다. 하드코딩이 아니라 YEAR 하나만 바꾸면 되고, 매년 1월 관리자 화면에서 갱신하는 구조를 전제로 했습니다
  • 209시간 고정을 없앴습니다. 월 소정근로시간을 주당 약정시간 × 4.345로 환산합니다. 주 20시간 근로자에게 209시간을 그대로 적용하면 기본급이 두 배 넘게 부풀려집니다. Step 2 상단에 환산된 시간을 실시간으로 보여줍니다
  • D-2 과정 유형 필드를 넣었습니다. 어학연수·전문학사·학사·석박사를 나눠 받고, 허용시간은 D2_LIMIT 테이블에서 조회합니다. 다만 이 값들은 전부 확인 필요 상태의 자리표시자입니다. 경고 문구도 단정하지 않고 '넘을 수 있습니다 / 방학·공휴일·토요일에는 제한이 없습니다 / 학교 국제처나 하이코리아에서 확인하세요'로 썼습니다
  • 음수 차액을 별도 분기했습니다. 실입금액이 계산값보다 많으면 체불 경고가 아니라 파란색 '계산 방식 차이' 카드가 나오고, 포괄임금제·상여·식대 가능성을 안내합니다. 진정서 버튼은 차액이 양수일 때만 나옵니다
  • 숙식비 공제 하한 경고를 넣었습니다. 숙식비를 뺀 뒤의 환산 시급이 최저임금보다 낮으면 빨간 경고가 뜹니다. 숙식 제공 형태(기숙사·원룸·식사만)도 함께 받습니다
  • OCR은 데모임을 결과에도 남깁니다. 버튼 밑에 '실제 인식이 아닌 데모'라고 적었고, 누르면 '샘플 값이 들어갑니다' 토스트가 뜬 뒤 수동 입력 위저드로 연결됩니다
  • 일급제를 추가했습니다. 기본급 = 일급 × 월 근무일수, 통상시급 = 일급 ÷ (주당 약정시간 ÷ 5)로 역산합니다
  • 결근 여부와 입사일을 받습니다. 결근이 있으면 주휴수당이 0이 되고, 1년 이상 여부를 직접 고르는 대신 입사일에서 재직일수를 계산합니다. 지각·조퇴는 결근이 아니라는 안내를 옆에 붙였습니다
  • 퇴직금에 통상임금 하한을 적용했습니다. 평균임금이 통상임금보다 낮으면 통상임금으로 계산합니다
// 핵심 산식 (calcWage 함수 그대로)
월소정근로시간   = 주당약정시간 × 4.345                 // 209 고정 아님
주휴시간(주)     = MIN(주소정, 40) / 40 × 8             // 15h 미만·결근 시 0
통상시급 시급제  = 입력 시급
         월급제  = 월급 / (월소정 + 월주휴)             // 주40h면 ≒ 209h
         일급제  = 일급 / (주당약정 / 5)
연장수당         = 연장h × 시급 × (5인↑ 1.5 / 5인↓ 1.0)
야간가산         = 야간h × 시급 × (5인↑ 0.5 / 5인↓ 0)
휴일수당         = MIN(휴일h,8)×시급×1.5 + 초과분×시급×2.0   // 5인↓는 모두 1.0
세전총액         = 기본급 + 주휴 + 연장 + 야간 + 휴일
실수령액         = 세전총액 − 세금공제 − 숙식비공제
퇴직금           = MAX(평균임금일액, 통상임금일액) × 30 × (재직일수/365)
차액             = 실수령액 − 실제입금액
                   양수 → 미지급 의심 · 진정서 연결
                   음수 → 계산 방식 차이 안내 (포괄임금 등)
