언어 전환 설계 — 이번에 정한 규칙

  • 선택 언어가 주, 한국어가 부. 어떤 언어를 골라도 한국어 표기는 아래에 작게 남김. 출입국사무소·은행 창구에서 실제로 말해야 하는 건 한국어 단어이기 때문에, 번역만 보여주면 현장에서 못 씀
  • 한국어 선택 시에는 부 표기를 숨김. 같은 말을 두 번 쓰지 않음
  • 고유명사·제도명은 번역하되 원어를 병기. ARC, E-9 같은 코드는 번역하지 않음
  • 북마크 세로 글씨. 한글은 글자를 세워서(upright), 영어·베트남어는 눕혀서(mixed) 표시. 라틴 문자를 세로로 세우면 읽기 어려움

수환이에게 넘길 때

  • 카테고리 데이터는 { id, icon, group, name:{ko,en,vi} } 구조. 언어가 늘어나면 name 객체에 키만 추가하면 됨
  • UI 문구(버튼·안내문)와 콘텐츠 문구(카테고리명·상세 설명)는 분리해서 관리. 콘텐츠는 노무사 감수 대상이라 번역본도 감수 이력을 따로 남겨야 함
  • 베트남어는 한국어보다 글자 수가 20~30% 길어짐. 카드·북마크 폭은 고정하지 말고 줄바꿈을 허용할 것
  • 기기 언어를 읽어 첫 실행 시 자동 선택하되, 설정 탭에서 항상 바꿀 수 있게 유지
